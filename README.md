# Santander Bootcamp 2026 - AI React Front-end

Repositório destinado ao armazenamento de projetos, desafios, exercícios e anotações desenvolvidos durante o **Santander Bootcamp 2026 - AI React Front-end**, promovido pela **DIO (Digital Innovation One)** em parceria com o **Santander**.

O objetivo deste repositório é documentar minha evolução ao longo da trilha, aplicando conceitos de desenvolvimento Front-end moderno, boas práticas de programação e integração com Inteligência Artificial.

---

# 🚀 Sobre o Bootcamp

O **Santander Bootcamp 2026 - AI React Front-end** é uma trilha de formação voltada ao desenvolvimento de aplicações web modernas utilizando as principais tecnologias do ecossistema JavaScript.

Durante o bootcamp, são abordados conceitos fundamentais e avançados de React, TypeScript, UI/UX Design, Git, GitHub e integração com Inteligência Artificial, proporcionando experiência prática por meio de desafios e projetos reais.
